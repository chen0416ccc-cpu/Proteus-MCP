# 布局与布线

`native_export` 和 `native_apply` 用于把任意受支持的语义电路转换为新原生文件，不是八灯生成器。电路拓扑、器件值、旋转和镜像来自模型，布局器不改电路。

## 自动流程

1. 读取基线主体或受支持的库绘图图元范围、可见引脚和标注样式，为完整字符串及出线留出空间。不再用引脚锚点矩形冒充器件主体，例如运放三角形可超出输入引脚的高度。
2. 按信号网络建立连接图，VCC/GND 不作为全器件相互吸引的边；分离的功能组分别排布。
3. 结合引脚朝向、连接强度和器件占用范围生成三个确定性候选布局。
4. 使用半格正交树连接信号网，分支处建立真实汇接点。只允许没有电气连接的直段内部垂直交叉，不允许端点、折点或 DOT 含混接触。
5. 在局部空位整理完整标注，运行共享检查，从通过的方案中按线长、折点、交叉和纸张面积选优。全失败时返回每个候选的原因。
6. 写入新的 `.pdsprj`，重新读取其 DSN/CDB、连接、几何和纸张，再运行同一质量检查。原模型不变。

这是一套有界启发式，不是通用最优布局器。器件上限为 100；当前静态主体解析覆盖直线、矩形和受支持多边形的声明范围。未知绘图/引脚图元、曲线、图内文字等尚未适配的主体会被拒绝，而不是猜测尺寸。描边保留余量，但不作逐像素测量保证。

## 控制位置

| 参数 | 行为 |
| --- | --- |
| `layout=auto` | 按网络关系自动放置，不走示例专用坐标。 |
| `layout=model` | 使用模型原有位置，不擅自移动。模型 10 单位对应原生一格，Y 方向相反。 |
| `placements` | `ref -> [x,y]` 原生整数格坐标，范围 ±500。自动模式将这些器件作为固定锚点，其他器件围绕它们放置。 |
| 未传 `sheet_size` | 自动布局按内容扩大**实际工程纸张**，基础尺寸为 100×70 格。手工模型/显式计划默认使用 100×70 格，不自行平移内容。 |
| `sheet_size` | 两个 20..1000 的偶数整数。显式尺寸不被悄悄放大；不足时返回错误。 |
| `wire_plan` | 显式正交通道与文字布局；仍需通过共享检查。给出文字 `at` 时该位置锁定，不为通过检查搬走。 |

没有显式文字位置时，标注可在原位置各轴六格内寻找空位，不改变文本、字体尺寸和用户选择的可见性。连续导线模式隐藏冗余**网络名**，网络身份仍写入文件并可回读；这不等于隐藏元件值。

## 检查与回执

信号网不能只靠同名标签满足默认连通检查。每个应连的可见引脚都必须指向真实导线，导线必须有两个有效端点，分支必须通过真实 DOT 连接。隐藏电源引脚由模型校验及文件网络比对核对，不凭空画出。

所有模式还检查器件与电源端子占用、文字互压/压器件/压导线、正交半格线、导线穿体、非法交叉及纸张范围。检查采用全文尺寸估计，覆盖旋转、镜像和非 ASCII 的保守宽度，不是本机字体的逐像素测量。合法交叉预算为 `max(4, 信号网数×2)`；端点曼哈顿跨度至少八格的单支路，绕行比例不得大于八。

| 返回字段 | 含义 |
| --- | --- |
| `routing.quality.passed` | 写入前通过本页范围内的检查。 |
| `routing.file_readback_quality.passed` | 最终保存文件通过同一检查，不仅是内存计划通过。 |
| `routing.quality.metrics` | 导线数、可见文字数、交叉、折点、格单位总线长和最大绕行比例。 |
| `routing.sheet` | 实际纸张、内容范围和全文估计是否在框内。 |
| `routing.layout_attempts` | 自动候选的得分或具体失败原因。显式计划不提供候选选优。 |
| `native_visual_verified` | 离线检查始终为 `false`，不能以此宣称原生画面已验收。 |

常见失败包括 `AUTO_LAYOUT_OUTSIDE_SHEET`、`AUTO_LAYOUT_CAPACITY`、`LABEL_SPACE_EXHAUSTED`、`QUALITY_MISSING_PIN_WIRE`、`QUALITY_DISCONNECTED_SIGNAL` 和 `SCHEMATIC_QUALITY_FAILED`。最后一种携带详细 `issues`。不应通过切换标签模式、缩小文字、隐藏数值或削弱断言来消除失败。

## 当前会话

上述自动布局与整图检查针对**新文件导出**，不会暗中改动正在打开的会话。`live_edit` 的原生变换只保留旧折点并更新端点。对已有原生引脚坐标的接线器件，MCP 会预先计算这种更新；会留下斜线或零长段时拒绝并返回 `LIVE_TRANSFORM_REQUIRES_REROUTE`。

这不是实时自动重布线。新增器件的原生几何尚未读回、未校准字体、当前页边界及完整实时碰撞检查不在这个预检的认证范围内；原生编辑仍非原子。保存、重开、原生目视和电路功能验证仍是[独立验收层](testing.md)。
