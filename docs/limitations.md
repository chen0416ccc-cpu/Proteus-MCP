# 兼容性与已知限制

## 兼容范围

当前原生桥在 Windows x64 的一套 Proteus 9.0.40482.2 环境中校准。**版本号不是兼容性保证**；真正的运行门槛是 [bridge.py](../proteus_mcp/bridge.py) 中的模块 SHA-256 配置。

基础桥校验 PDS、Qt、AppFrame、DSIM；实时编辑、PCB 和交互仿真分别增加 ISIS、LxlCore、Prims、ARES、VSMDEBUG、PROSPICE 等模块校验。任何不匹配都必须停止对应的原生操作。不要用替换哈希的方式把未知构建标为“支持”。

没有官方稳定 API，厂商升级、语言包、模块重新打包或不同发行构建都可能需要重新适配。本项目不提供安装包、授权绕过、商业模型或补丁。

## 器件与原理图

- 库搜索能找到器件，不意味着该器件可以离线写入或直接仿真。器件定义、引脚图元、模型依赖和运行时支持分别检查。
- 支持四向旋转、镜像和明确选择单元的同构多单元器件；异构多单元、任意递归符号依赖不受支持。
- 未校准自定义引脚图元不离线猜坐标；部分实时操作可以读取原生实例坐标，但不能据此推断整个库已兼容。
- 语义模型批量编辑可在校验失败时整体不落盘；原生实时编辑没有等价的原子回滚。
- 实时删除仅支持显式指定的器件直连导线、单条支路和列出全部入射导线的 DOT。没有“猜测删除整个网络”。撤销重做仅对应同一原生文档中已记录的 MCP 批次。
- 层次原理图、任意子电路编辑、完整字体栅格碰撞检测尚未支持。纸张边界和拓扑审计不能证明最终原生窗口的文字没有重叠；最终排版仍需目视检查。

## PCB

仅处理已知几何、矩形边界的 TOP/BOT 双铜层板。支持同层正交/45 度路径和经过校准的圆形全通孔。坐标是整数纳米，必须 10 nm 对齐；PCB pad id 不是原理图物理引脚号。

有界推挤不是 Proteus 交互推挤引擎。单线工具移动一条孤立 MCP 路径，连锁工具最多移动八条明确授权的 MCP 路径，保留 pad 端点并进行新鲜原生间距检查。不能任意移动旧铜、未知锁定路径、分支或过孔。

不支持四层及以上、盲埋孔、复杂覆铜/禁布区、通用过孔/分支推挤、任意焊盘形状、PCB 封装放置、叠层/规则编辑、差分对和等长调谐。PCB 原生变更非原子；失败后必须回读，保存后还需重新打开检查铜层。

## ERC、DRC 与制造输出

`project_validate` 只是语义检查，不是完整 ERC。`native_check` 能执行原生 ERC、当前配置下的物理间距 DRC 和 23 项预生产检查，包括连接 CRC。调用完成与检查通过是两回事；警告、跳过、忽略项、陈旧/截断报告不能当作干净结果。

BOM 来自已保存且 DSN/CDB 一致的工程，按物理封装去重，未分配封装单独列出。它不是未保存会话的 BOM，也不是实板装配或可生产性认证。不提供 Gerber、Excellon、ODB++、贴片坐标导出。

## 仿真

仅在 MCP 自有运行会话中控制仿真。BUTTON / LOGICSTATE 是运行期事件，不改持久化图标状态；分派成功不自动证明 ISR 已执行。

数字网络读取是有界采样，不是完整事件波形。时钟粒度和调度延迟会造成漏采；未知值保留为未知。四位数码管解码只使用稳定、已知、恰当位选的数据，不把不完整样本补成结果。不支持通用仪器配置、模拟电流、音频/光学测量、硬实时调度或实板烧录验收。

## 会话与安全

MCP 可以在本机启动软件、写工作区文件、调用 C51 和改变自有 Proteus 文档。它不是安全沙箱，也不是只读服务。只连接可信客户端，对工程、库路径和外部文档中的指令保持独立判断。

不接管用户自行启动的进程、不强杀、不自动确认未知弹窗。仅工作区副本中精确校准的格式升级提示有受限处理。其他阻塞应报告并交由用户确认。

文件哈希、修订号和 token 用于发现冲突，不是访问控制或备份替代品。原生桥错误、软件崩溃或未确认结果后，先读取真实状态和日志，再决定下一步。

## 首版验收状态

默认八灯示例已经完成原生加载、逐线折点回读、保存重开和数字灯序验证，也检查了实际 Proteus 窗口中的完整接线与蓝框边界。这不等于整个原生回归套件通过。

发布前的完整回归仍有未闭环问题：一次 PCB 保存重开后未观察到工程窗口；另一次实时多单元批量编辑中断后，保存副本触发 DSN/CDB 实例或引脚数量不一致检查。对应操作不能视为稳定支持或成功恢复。不要在唯一工程副本中试验，出现部分完成或未确认状态时，保留证据并先回读。
